# Fleet Manager Pro 🚛️

A comprehensive desktop application for fleet and vehicle management, featuring full offline capabilities, bilingual support (English/Urdu), and real-time local database tracking.

---

## ✨ Features

*   Offline First: Fully functional offline. All data is stored locally on your computer using SQLite.
*   Bilingual Support: Complete English and Urdu language toggle.
    *   Instant switching between languages.
    *   Right-to-Left (RTL) layout support for Urdu script.
    *   Built-in "Nastaliq" fonts for beautiful Urdu typography.
*   Comprehensive Modules:
    *   Dashboard: Overview of fleet statistics and financial balance.
    *   Vehicle Management: Track vehicle details, purchase dates, and status.
    *   Trips: Log routes, distances, and purposes.
    *   Diesel & Fuel: Record fuel consumption, costs, and odometer readings.
    *   Spare Parts: Manage inventory and monitor stock levels.
    *   Cashbook: Track income, expenses, and online/bank transactions.
*   Print Ready: Generate clean reports and invoices directly from the interface.

## 📘 Usage Guide

1.  Launch the App:
    *   Double-click the desktop icon to start.
2.  Language Toggle:
    *   Click "اردو (Urdu)" in the top sidebar to switch the entire interface to Urdu.
    *   Click "English" to switch back.
3.  Data Entry:
    *   When in Urdu mode, type directly into input fields. The text will render in Nastaliq script and align to the right automatically.

## 💻 System Requirements

*   Operating System: Windows 10 or higher.
*   Disk Space: 50 MB free space required for installation. Data storage is effectively unlimited (limited only by your hard drive).

---

## 🐛 Troubleshooting

Q: The app opens but the screen is white/blank.
*   A: This usually happens if the frontend bundle wasn't downloaded during install. Ensure you have an active internet connection while running the installer.

Q: Can I access my data on another computer?
*   A: No, this is a desktop offline application. Data is stored in a local file on the specific computer used. To transfer data, copy the `fleet.db` file located in your AppData folder.
